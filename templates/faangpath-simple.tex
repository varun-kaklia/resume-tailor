%% ===== PLACEHOLDER MARKERS =====
%% src/core/render/latex.ts substitutes every marker in ONE pass, so nothing it
%% inserts is ever rescanned. A marker is a name wrapped in three angle brackets
%% each side; the names are listed bare below precisely because writing them
%% wrapped here would make this comment block substitutable too.
%%
%%   NAME        full name, escaped
%%   CONTACT     one line: email, phone, location, links
%%   SUMMARY     complete Summary section, or empty
%%   EDUCATION   complete Education section, or empty
%%   EXPERIENCE  complete Experience section, or empty
%%   PROJECTS    complete Projects section, or empty
%%   SKILLS      complete Skills section, or empty
%%
%% All seven must appear in the body below, and no other marker may, or the
%% render throws RENDER_FAILED. Section bodies carry their own \section heading,
%% so an empty section leaves no orphan rule behind.
%% ================================
